# Roadmap

## 1.0 · 当前版本

- 可复现的 processed news 数据集与语义 KG；
- 原始页面、独立新闻与 KG 投影之间的强制溯源；
- 编号标题、访谈话题、分隔符、description 与人工 override 拆分；
- 新闻拆分置信度和待审页面报告；
- 事件、主体、地点、主题与命名对象 facet；
- 独立新闻解析与 12 类通用事件分类；
- 标准地名表、受控主题与高置信命名模式；
- 分维度覆盖率与审查样本；
- 仅表达时序的证据关系；
- append-only 上游同步与显式语义重建；
- 关键词搜索和组合条件检索首页；
- 实体相关新闻时间线与可交互 KG；
- 独立 Ontology 类型和覆盖率浏览页；
- GitHub Pages 静态部署。

## 已实现：层级本体基础（2.3 / 4.1）

- 语义定义单一来源、确定性编译和新鲜度验证；
- 三套明确区分的实体类、行动、议题层级及既有身份映射；
- 8 个一级议题领域 / 27 个既有主题的真实父级筛选、去重和命中解释；
- KG/状态指纹防止同版本静默混合；既有新闻与图谱内容保持不变；
- 基础阶段行动定义保留为草案，后续仅逐类启用具备独立证据规则的具体类。

## 已实现：图谱维护与受审查身份

- 归一化来源/新闻版本、精确证据、抽取断言及独立支持；支持数不冒充独立证实数
- 固定输入的全量候选重算、独立重放、全局依赖和确定性差异；无变化复用原版本
- 精确审查后的来源修订、撤回与恢复；保留失效支持、休眠身份与历史引用
- 草稿审计包读回后原子接受六个输出/来源指针/接受清单；接受后公开审计，失败核实恢复
- 同语义版本前向回滚；语义变化走正常审核的代码与重新生成数据 PR
- 新闻级实体归属的受审查合并、拆分、清除和复活；原始抽取与每条新闻支持保持独立
- Actions 接入已实现；首次真实运行及部署结论以对应工作流记录为准

## 已实现：保守行动与变化评估（2.4 / 4.2）

- 司法、工程、同比/环比数量变化的独立本新闻证据规则及局部计划/预测/条件/否定限定
- applicable / not_applicable / undetermined 三态，未命中默认未确定；明确不适用需要精确人工审查
- 精确 occurrence witness、新闻级断言支持、撤回/恢复、受审查迁移差异及可见筛选
- 行动分配不代表现实发生，不替代独立的新闻类型或数值 Observation 建模；详见 [行动评估](action-assessments.md)

## 剩余阶段与验收条件

1. 独立报道形式与数值 Observation：[首个受限迁移提案](report-descriptions.md)已实现经审查形式契约、严格整句数值模板、支持生命周期与独立重放路径；仍需完成整套候选迁移验证和发布审查。报道形式审查表为空，数值模板不声明广泛覆盖，不能用行动模态或旧领域类型替代
2. 更细身份迁移：在实际 mention-span 与明确旧新边界映射就绪后，才允许同一新闻内
   同名对象区分、新闻拆分/合并、来源改名/路径复用；必须保留逐条来源与历史支持
3. 跨语义版本恢复：经审查恢复相配的代码/配置/输出，不只回退数据；错配必须拒绝
4. 依赖驱动局部重算是后续优化：先证明与固定输入全量结果等价，不替换当前安全默认

## 下一步

- 为新闻片段增加可读 Markdown 锚点；
- 逐步处理 `news-segmentation.json` 中的低置信回退页面；
- 建立同一事实的跨来源事件合并队列；
- 进一步降低 `other` 事件比例，但不牺牲分类边界；
- 引入经过审查的中国地级市标准表；
- 积累有真实来源依据的新闻级身份审查记录，默认空表不自动猜测同名关系。

## 暂不做

- 不自动推断因果或立场；
- 不把低置信一次性字符串当成实体；
- 不复制完整原文；
- 不让增量任务静默执行语义迁移；
- 不依赖长期运行的后端服务。
