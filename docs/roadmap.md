# Roadmap

## 1.0 · 当前版本

- 可复现的 processed news 数据集与语义 KG；
- 原始页面、独立新闻与 KG 投影之间的强制溯源；
- 编号标题、访谈话题、分隔符、description 与人工 override 拆分；
- 新闻拆分置信度和待审页面报告；
- 事件、主体、地点、主题与命名对象 facet；
- 独立新闻解析与 12 类通用事件分类；
- 标准地名表、受控主题与高置信命名模式；
- 分维度覆盖率与审查样本；
- 仅表达时序的证据关系；
- append-only 上游同步与显式语义重建；
- 关键词搜索和组合条件检索首页；
- 实体相关新闻时间线与可交互 KG；
- 独立 Ontology 类型和覆盖率浏览页；
- GitHub Pages 静态部署。

## 已实现：层级本体基础（2.3 / 4.1）

- 语义定义单一来源、确定性编译和新鲜度验证；
- 三套明确区分的实体类、行动、议题层级及既有身份映射；
- 8 个一级议题领域 / 27 个既有主题的真实父级筛选、去重和命中解释；
- KG/状态指纹防止同版本静默混合；既有新闻与图谱内容保持不变；
- 行动定义仅为草案，不把旧报道领域冒充已抽取行动。

## 后续分阶段实现

1. 证据与支持：显式 SourceVersion、NewsRevision、EvidenceSpan、ExtractionRun、
   AssertionRevision/Support、身份登记和审计记录；继续拒绝真实来源修改/删除；
2. 完整候选重算：固定输入版本与全局依赖，产出可审查的实体/断言/关系差异；
   覆盖出现门槛、全局名称重扫、热门实体上限、时间插入与日期锚点；
3. 受审查的修订/撤回与可逆 merge/split：撤回失效支持，保留仍有效支持与休眠身份；
4. 原子版本发布与回滚：来源基线、新闻、KG、索引和发布 manifest 共同提交；
5. 只有与全量候选等价性证明充分后，才考虑依赖驱动的局部重算。

## 下一步

- 为新闻片段增加可读 Markdown 锚点；
- 逐步处理 `news-segmentation.json` 中的低置信回退页面；
- 建立同一事实的跨来源事件合并队列；
- 进一步降低 `other` 事件比例，但不牺牲分类边界；
- 引入经过审查的中国地级市标准表；
- 为主体别名归并建立可审查映射。

## 暂不做

- 不自动推断因果或立场；
- 不把低置信一次性字符串当成实体；
- 不复制完整原文；
- 不让增量任务静默执行语义迁移；
- 不依赖长期运行的后端服务。
