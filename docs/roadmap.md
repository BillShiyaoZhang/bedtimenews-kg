# Roadmap

## 0.1 · 当前版本

- 静态实体检索、事件时间线与关系图；
- 原文溯源；
- 浏览器内 ontology / KG 编辑；
- 确定性 Markdown 解析和实体词典匹配；
- 8 个内容栏目的全量事件索引；
- submodule 上游跟踪和 append-only 自动同步；
- 上游修改、删除与疑似改名的审查隔离；
- 数据校验与 GitHub Pages 部署。

## 0.2 · 数据扩展

- 为更多栏目建立经过审查的实体词典；
- 加入事件合并队列，处理同一事实的多篇报道；
- 为来源增加 Git commit SHA 和段落定位；
- 生成覆盖率、孤立节点与关系密度报告。

## 0.3 · 协作审查

- 用 JSON Patch 表达网页编辑结果，减少 PR 冲突；
- 为关系增加“提出 / 复核 / 否决”的审查状态；
- 比较 ontology 版本对已有数据的影响；
- 提供可复制的查询链接和事件路径引用。

## 暂不做

- 不在没有证据的情况下自动生成因果关系；
- 不把完整原文复制进 KG；
- 不依赖必须长期运行的后端服务；
- 不把模型输出直接视为已验证事实。
