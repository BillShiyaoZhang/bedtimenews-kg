# Roadmap

## 1.0 · 当前版本

- 单一全量、可复现的语义 KG；
- 事件、主体、地点、主题与命名对象 facet；
- 分段事件解析与 12 类通用事件分类；
- 标准地名表、受控主题与高置信命名模式；
- 分维度覆盖率与审查样本；
- 仅表达时序的证据关系；
- append-only 上游同步与显式语义重建；
- 关键词搜索和组合条件检索首页；
- GitHub Pages 与 Sites 部署。

## 下一步

- 为来源增加上游 Git commit 与段落锚点；
- 建立同一事实的跨来源事件合并队列；
- 进一步降低 `other` 事件比例，但不牺牲分类边界；
- 引入经过审查的中国地级市标准表；
- 为主体别名归并建立可审查映射。

## 暂不做

- 不自动推断因果或立场；
- 不把低置信一次性字符串当成实体；
- 不复制完整原文；
- 不让增量任务静默执行语义迁移；
- 不依赖长期运行的后端服务。
