# Roadmap

## 1.0 · 当前版本

- 可复现的 processed news 数据集与语义 KG；
- 原始页面、独立新闻与 KG 投影之间的强制溯源；
- 编号标题、访谈话题、分隔符、description 与人工 override 拆分；
- 新闻拆分置信度和待审页面报告；
- 事件、主体、地点、主题与命名对象 facet；
- 独立新闻解析与 12 类通用事件分类；
- 标准地名表、受控主题与高置信命名模式；
- 分维度覆盖率与审查样本；
- 仅表达时序的证据关系；
- append-only 上游同步与显式语义重建；
- 关键词搜索和组合条件检索首页；
- 实体相关新闻时间线与可交互 KG；
- 独立 Ontology 类型和覆盖率浏览页；
- GitHub Pages 静态部署。

## 下一步

- 为新闻片段增加可读 Markdown 锚点；
- 逐步处理 `news-segmentation.json` 中的低置信回退页面；
- 建立同一事实的跨来源事件合并队列；
- 进一步降低 `other` 事件比例，但不牺牲分类边界；
- 引入经过审查的中国地级市标准表；
- 为主体别名归并建立可审查映射。

## 暂不做

- 不自动推断因果或立场；
- 不把低置信一次性字符串当成实体；
- 不复制完整原文；
- 不让增量任务静默执行语义迁移；
- 不依赖长期运行的后端服务。
